# IPL Analytics Dashboard

A full-stack data analysis and ML dashboard for cricket analytics.

## Features
- 11 interactive analytics pages
- Machine learning win predictor
- Real-time data visualization
- Optimized database

## Tech Stack
Python, Streamlit, FastAPI, SQLite, Scikit-learn, Plotly

## Live Demo
https://your-username-ipl-analytics.streamlit.app

## Local Setup
```bash
pip install -r requirements.txt
python api.py
streamlit run app.py
```

Visit: http://localhost:8501
